# Snake Game 🐍

A classic Snake game built with Python and Pygame, featuring custom-made green snake sprites and a banana instead of the traditional apple.

Features

Custom Snake Sprites: A green snake with custom sprites for a more personalized look.

Banana Collectibles: Collect bananas to grow your snake and increase your score.

Classic Gameplay: Control the snake, collect food, and avoid colliding with yourself.

Built with Pygame: Uses Pygame for rendering, keyboard input, and game mechanics.


# Requirements

Python 3.x

Pygame


# Controls



Arrow Keys


Up / Down / Left / Right
